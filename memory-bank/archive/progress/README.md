## Politique d’archivage

- Le suivi courant reste dans [`memory-bank/progress.md`](../../progress.md).
- Les détails durables d’une tâche doivent être placés dans [`memory-bank/tasks/`](../../tasks/) et son statut dans [`memory-bank/tasks/_index.md`](../../tasks/_index.md).
- Les rapports techniques détaillés vont dans `doc/` lorsque cela est approprié.
- Une nouvelle archive peut être créée lors d’une prochaine compaction, avec une date ISO dans son nom.
- Les archives sont conservées verbatim et ne doivent pas être supprimées sans décision explicite.
